# Changelog

## 0.1.0

- First version: a daily colony newspaper, written by the colony teacher (or a library student) from the previous day's colony events. A citizen walks up and hands you a copy, saying a line about it.
- A chapter in Talking Colonists' Colony Handbook explains how to use it, and citizens know it too, so you can ask them (Talking Colonists versions with the handbook).
